# For You, With All My Heart ♡

A responsive, self-contained apology website made to say sorry with care, accountability, and room for the other person to choose their own pace.

## Features
- Animated opening screen, floating hearts/petals, scroll reveals, and heart confetti.
- Apology letter, specific commitments, and gentle closing choices.
- Optional original synthesized melody (starts only when tapped).
- Responsive mobile layout, keyboard focus states, live response announcements, and reduced-motion support.
- No frameworks, build dependencies, external fonts, tracking, or API keys.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **GitHub Actions** as the source.
3. Open **Actions** and enable workflows if prompted.
4. Push to `main` (or run **Deploy apology website** manually). The workflow uploads this static site and deploys it to Pages.

The site does not submit or store her response anywhere; the buttons only show a message on the page. Edit the letter in `index.html` to make the wording more personal before sharing.
